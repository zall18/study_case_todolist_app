## Prasyarat
- Flutter SDK (Dart SDK `^3.9.2`)
- Emulator Android / iOS atau perangkat fisik yang sudah terhubung

## Cara Menjalankan (How to Run)

1. **Unduh dependensi project:**
   ```bash
   flutter pub get
   ```
2. **Pastikan perangkat/emulator terdeteksi:**
   ```bash
   flutter devices
   ```
3. **Jalankan aplikasi:**
   ```bash
   flutter run
   ```

## Analisis & Pengujian
- **Cek static analysis:**
  ```bash
  flutter analyze
  ```
- **Jalankan widget test:**
  ```bash
  flutter test
  ```

## Build APK (Android)
1. **Build APK release:**
   ```bash
   flutter build apk --release
   ```
2. **Lokasi file APK hasil build:**
   `build/app/outputs/flutter-apk/app-release.apk` (bisa langsung dipasang di HP Android untuk pengujian).
